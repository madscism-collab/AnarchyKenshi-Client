# Kenshi Multiplayer - client updates

This repository holds the release files of the Kenshi Multiplayer client.
**You do not need to download anything from here.**

The mod's launcher (the window that opens when you start Kenshi with the mod
enabled) checks the latest release here on every start. When a new version is
out, the PLAY button turns into a blue UPDATE button, and one click installs it.

Every release is signed. The launcher installs a file only if it matches the
signed list in `manifest.txt`; anything else is refused.

Each release contains:

* `AnarchyKenshi.dll`, `AnarchyCore.dll`, `AnarchyLoader.dll`, `AnarchyLauncher.dll`
* `AnarchyNews.txt` - the list of changes shown in the launcher
* `manifest.txt` - the signed list of the files above
